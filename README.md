# 💻 Desenvolupament web en entorn client

## 📚 Informació de l'assignatura

Aquest repositori conté les pràctiques, exercicis i activitats de l'assignatura **M0612 - Desenvolupament web en entorn client**, del cicle formatiu de Desenvolupament d'Aplicacions Web (DAW).

L'objectiu és aprendre a crear pàgines web interactives utilitzant principalment JavaScript i altres tecnologies del desenvolupament web en entorn client.

🔗 [Accedir al Moodle de l'assignatura](https://www.sapalomera.cat/moodlecf/course/view.php?id=88)

---

## 📖 Temari

### 🟦 NF1 — Tema 1

**Sintaxi del llenguatge. Objectes predefinits del llenguatge. Estructures i objectes definits pel programador.**

En aquest tema treballarem els conceptes bàsics de JavaScript, la seva sintaxi, les estructures de control i la creació d'objectes.

📁 Carpeta: `NF1`

📌 [Accedir al Tema 1](https://www.sapalomera.cat/moodlecf/course/view.php?id=88&section=1)

---

### 🟩 NF2 — Tema 2

**Esdeveniments. Manejament de formularis. Model d'objectes del document.**

En aquest tema aprendrem a treballar amb esdeveniments, formularis i el DOM per modificar i fer interactives les pàgines web.

📁 Carpeta: `NF2`

📌 [Accedir al Tema 2](https://www.sapalomera.cat/moodlecf/course/view.php?id=88&section=2)

---

### 🟨 NF3 — Tema 3

**Comunicació asíncrona client-servidor.**

En aquest tema treballarem la comunicació entre el client i el servidor de manera asíncrona, utilitzant tecnologies com AJAX i les peticions HTTP.

📁 Carpeta: `NF3`

📌 [Accedir al Tema 3](https://www.sapalomera.cat/moodlecf/course/view.php?id=88&section=3)

## 🎯 Objectius

* Aprendre els fonaments de JavaScript.
* Treballar amb objectes i estructures de control.
* Gestionar esdeveniments i formularis.
* Manipular el DOM.
* Entendre la comunicació asíncrona entre client i servidor.
* Desenvolupar pàgines web més interactives.
